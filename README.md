## Now building

### SITENOA

A template-driven website builder, built as a SaaS. You pick one of **14 designed templates** across 7 categories, fill in your own content in a structured editor, adjust colours, fonts and sections, and publish to a public URL. Published sites collect RSVPs, enquiries, table reservations and event registrations into the owner's dashboard.

It's deliberately *not* a free-form page builder: you edit inside designed sections, so the result always looks finished.

- **Two-panel editor** with live preview, undo history and a section library of 25 section types
- **Postgres with row-level security** doing the business rules, plus custom domains, admin panel and billing
- **Tested at every layer:** unit tests, database tests against the real migrations, and Playwright end-to-end

`Next.js 16` `React 19` `TypeScript` `Tailwind CSS 4` `Supabase` `Postgres + RLS` `Razorpay` `Resend` `Vercel` `Vitest` `Playwright`
